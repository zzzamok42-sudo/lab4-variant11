# Lab 4, variant 11: printshop

Учебный проект на Go для расчета стоимости услуг типографии.

## Функции пакета `printshop`

- `PageCost` рассчитывает стоимость печати указанного количества страниц.
- `OrderCost` рассчитывает стоимость тиража с учетом количества копий.
- `ApplyBulkDiscount` изменяет стоимость через указатель и применяет скидку в процентах.
- `FormatPrintReport` формирует текстовый отчет о заказе.

Функции проверяют отрицательные и нулевые значения, некорректную скидку, пустой идентификатор заказа и `nil`-указатель.

## Использованные пакеты GitHub

- [github.com/fatih/color](https://github.com/fatih/color) используется для цветного заголовка отчета.
- [github.com/google/uuid](https://github.com/google/uuid) используется для создания идентификатора заказа.

## Запуск

Из каталога проекта выполните:

```bash
go mod tidy
go run ./cmd/app
```

## Документация

Документацию пакета можно посмотреть командой:

```bash
go doc ./pkg/printshop
```

Для запуска локального сервера `godoc` установите инструмент и выполните:

```bash
go install golang.org/x/tools/cmd/godoc@latest
godoc -http=:6060
```

После этого документация будет доступна по адресу `http://localhost:6060`.
